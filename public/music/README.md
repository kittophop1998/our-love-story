# Music Folder

วางไฟล์เพลง .mp3 ของคุณในโฟลเดอร์นี้

## วิธีใช้งาน:

1. เตรียมไฟล์เพลง .mp3 ที่ต้องการ
2. เปลี่ยนชื่อไฟล์เป็น `love-song.mp3` หรือแก้ไขชื่อในโค้ด
3. วางไฟล์ในโฟลเดอร์นี้
4. รีเฟรชหน้าเว็บเพื่อให้เพลงเล่น

## ตัวอย่างชื่อไฟล์:
- love-song.mp3 (default)
- background-music.mp3
- romantic-music.mp3

## หมายเหตุ:
- ขนาดไฟล์ไม่ควรเกิน 10MB เพื่อประสิทธิภาพที่ดี
- ใช้ไฟล์ที่มีคุณภาพเสียง 128-192 kbps ก็เพียงพอ
- ตรวจสอบลิขสิทธิ์เพลงก่อนนำไปใช้
